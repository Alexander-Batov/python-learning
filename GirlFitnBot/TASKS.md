# TASKS.md — очередь задач для автономной работы

Работай строго по порядку: берёшь один пункт → выполняешь → ставишь `[x]` → делаешь
`git commit` → переходишь к следующему. Не начинай новый пункт, пока не закрыт текущий.
Если пункт невыполним (блокер, нехватка данных, противоречие) — не останавливайся:
опиши блокер в конце этого файла в разделе «Блокеры» и переходи дальше.

## Источники истины (прочитай перед стартом)
- `Структура_данных.md` — продуктовая спецификация: экраны, логика, данные, дизайн-токены.
- `Мотивационная_система.md` — геймификация + требование осветления (раздел «Осветление»).
- `Экраны/Референс_дизайн_полный.png` — главный визуальный референс (тон, светлость, стиль).
- `Экраны/01_Сегодня_v2.png` — референс экрана «Сегодня» (структура блоков).

Приоритет при расхождениях: `Мотивационная_система.md` (по тону и светлости) >
`Структура_данных.md` (по токенам и логике) > старые скриншоты.

## Жёсткие правила (без исключений)
- Никаких медицинских утверждений; прогнозы цикла — «ориентировочно».
- Не обнулять прогресс, никакой вины («серия прервана», «ты пропустила» — запрещены).
- Тексты уведомлений и карточек — только поддерживающие.
- День цикла/фаза не хардкодятся — считаются из данных пользователя.
- Не трогать `.env`, секреты, конфиги деплоя. Не делать `git push`.
- Точечные правки: работающие части демо не переписывать без необходимости.
