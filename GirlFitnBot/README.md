# GirlFitnBot — Telegram Mini App женского здоровья и wellness

Персональный помощник по женскому здоровью и образу жизни
(спецификация — `Структура_данных.md`). Формула продукта:
**Цикл → состояние → рекомендации → действие → привычка → результат**.

Telegram-бот на **aiogram 3** (long polling) + мини-апп (ванильный JS/CSS,
мультифайл без сборки) с веб-сервером **aiohttp** в том же event loop.
Данные — SQLite. Деплой — Amvera.

> ⚠️ **Контент — демо-заглушки.** Тексты фаз, тренировки, рецепты и юрдокументы
> написаны как дружелюбные черновики и **не являются медицинскими советами**.
> Перед публикацией заменяются материалами клиентки и при необходимости
> проходят проверку специалистом. Фото/видео — градиентные плейсхолдеры.

## Что уже работает

### Бот
- `/start` — приветствие и reply-кнопка открытия мини-аппа (WebAppInfo).
  Если данных цикла нет — в приложении запустится onboarding.
- Онбординг в боте (FSM): имя → дата начала последних месячных (ДД.ММ.ГГГГ,
  не в будущем) → длина цикла (21–35, дефолт 28) → длительность месячных (2–8,
  дефолт 5). `/reset_cycle` — сброс и перезапуск.
- Планировщик уведомлений (`notify.py`): план дня 09:00, тренировка 18:00
  (если не отмечена), вечерний чек-ин 21:00, за день до ожидаемой менструации,
  напоминания привычек по заданному времени. Все типы независимо отключаемы
  (настройки в приложении). Время серверное (UTC на Amvera).

### Приложение (5 разделов)
- **Сегодня** — карточка цикла (день, фаза, индикатор цикла, «до менструации
  ориентировочно ≈ N дн.»), фраза дня по фазе, тренировка дня (градиентная
  главная карточка по референсу спеки), фокус питания, привычка дня
  (○→✓ в один тап), мини-чек-ин «Энергия/Настроение/Самочувствие» с
  автосохранением, прогресс дня «N из 3».
- **Цикл** — календарь месяца по фазам, отметка начала месячных, симптомы
  дня (интенсивность, боль, сон, аппетит, тяга, вздутие, другие), точки дней
  с отметками, карточка текущей фазы, 4 карточки фаз → информационные экраны,
  «Изменить данные цикла» (дата/длина/длительность — правка в любой момент),
  деликатная карточка задержки цикла.
- **Активность** — тренировка дня (рекомендация из общей библиотеки по фазе,
  детерминированный выбор по дате), мягкая альтернатива «сегодня не хочется
  интенсивно», фильтры (категория/длительность/интенсивность), каталог
  тренировок (20 шт.: силовые/кардио/йога/растяжка/восстановление),
  «на этой неделе N/4», месяц (тренировки · минуты · % выполнения), плеер
  тренировки: до (что понадобится, структура разминка/основной блок/заминка)
  → во время (этап, таймер, пауза/пропустить) → после («Отметить выполненной»).
- **Питание** — карточка цикла, фокус дня с визуальной тарелкой (½/¼/¼ + жиры),
  «Обрати внимание на» (белок/клетчатка/жиры/жидкость с пояснением «зачем»),
  «Что приготовить сегодня?», рецепты с фильтрами (завтрак/обед/ужин/перекус,
  быстро/бюджетно/минимум ингредиентов/без готовки/meal prep), экран рецепта,
  конструктор тарелки (Белок → Овощи/фрукты → Углеводы → Жиры → «Твоя тарелка
  готова ✓»), питание по 4 фазам, трекер приёмов пищи (только факт отметки,
  без оценок), регулярность. Дисклеймер ⓘ в шапке.
- **Привычки** (в «Сегодня» и «Профиле», отдельной вкладки нет) — фокус недели,
  «мои привычки» с частотой и прогрессом, добавление (категория → частота →
  напоминание), прогресс («12 выполнений · 78% регулярность», мини-календарь
  ✓/○, «Ты становишься регулярнее 💛»), мягкая адаптация к лютеиновой фазе.
- **Профиль** — имя (редактирование), 🌸 Мой цикл, 🎯 Мои цели (мультивыбор),
  📊 Мой прогресс за месяц + карточка регулярности с динамикой по неделям,
  ⭐ Подписка (мок), настройки (5 типов уведомлений, единицы кг/фунты и
  см/дюймы, приватность), **удаление аккаунта и всех данных**, помощь (FAQ +
  поддержка), блок «Эксперты», юрблок (соглашение/политика/согласие — заглушки,
  версия).

### Onboarding (в приложении, 5 шагов)
Приветствие («Забота о себе — это не цель. Это образ жизни») → имя → данные
цикла (с опцией «Не знаю» → стандартные 28/5, правится позже) → цели
(мультивыбор из 5) → уведомления (Да/Позже). Первый вход без данных —
онбординг вместо приложения. Бот-онбординг сосуществует (та же таблица users).

### API (/api/*, все эндпоинты требуют валидный initData)
`GET/POST /api/cycle` (дата/длина/длительность/имя/цели/уведомления) ·
`GET /api/today` · `GET/POST /api/wellbeing` · `GET/POST /api/symptoms` ·
`GET /api/workouts` (+ фильтры) · `GET /api/workouts/daily` ·
`POST /api/workouts/complete` · `GET /api/recipes` · `GET /api/recipes/{id}` ·
`GET/POST /api/nutrition` · `GET/POST /api/habits` ·
`POST /api/habits/{id}/toggle` · `PATCH /api/habits/{id}` ·
`GET /api/progress?month=` · `GET/PATCH /api/user` · `DELETE /api/user`.

День цикла и фаза не захардкожены — считаются из данных пользователя
(`cycle.py` ↔ `webapp/cycle.js`, классическая схема фаз; задержка цикла —
деликатный статус, не ошибка). Прогнозы формулируются «ориентировочно».

### Локальное тестирование API без Telegram
```bash
python scripts/make_initdata.py            # валидный initData токеном из .env
curl "http://localhost:8080/api/today?initData=<вставить>"
```

## Локальный запуск

```bash
pip install -r requirements.txt
cp .env.example .env   # заполните BOT_TOKEN и WEBAPP_URL (для Mini App нужен
                       # публичный HTTPS: ngrok http 8080 → URL в WEBAPP_URL)
python bot.py
```

- `http://localhost:8080` отдаёт мини-апп; `curl ".../api/cycle?initData=bad"` → 401.
- В обычном браузере приложение покажет экран «Откройте через Telegram-бота»:
  без запуска через web_app-кнопку initData пуст, API работать не будет.
- `DEBUG=1` — подробные логи цепочки «сохранение → API → ответ».

## Деплой на Amvera

Long polling — публичный IP для бота не нужен, нужен только HTTPS-доступ
к мини-аппу. См. прежний порядок в истории README: python 3.11, pip,
запуск `bot.py`, `PORT=80`, секреты — переменными окружения (`.env` в git
не коммитится).

**Данные.** `amvera.yml` монтирует персистентный диск в `/data`. Если
`DB_PATH` не задан, код сам кладёт БД в `/data/users.db` (страховка от
потери пользователей при пересоздании контейнера); явный `DB_PATH` в
панели по-прежнему имеет приоритет. После деплоя проверьте в логах
строку запуска и убедитесь, что данные переживают перезапуск.

**Если деплой падает на «Downloading the archive from S3 … 404».**
Архив с кодом загружает в своё S3 сама Amvera на шаге сборки; 404 на
скачивании означает, что шаг загрузки не завершился (сбой интеграции с
GitHub или платформы), а «Перезапуск» пытается скачать несозданный
архив. Лечится не перезапуском, а НОВЫМ деплоем: панель → проект →
«Обновить»/«Пересобрать». Если повторяется — перепривязать репозиторий
(токен GitHub мог протухнуть) или пушить напрямую в git-репозиторий
Amvera (`git remote add amvera <url из панели>`, `git push amvera master`).

## Наполнение и правки

- **Тексты интерфейса** — только `webapp/content.json` (фразы дня по фазам,
  фокусы питания, FAQ, юрблок, onboarding).
- **Библиотеки** — `webapp/data/*.json` (тренировки/рецепты/привычки);
  сидятся в БД при первом старте, правка файла + удаление таблицы = новый контент.
- **Методика фаз** — `webapp/cycle.js` и `cycle.py` (менять в обоих).
- **Дизайн** — токены в начале `webapp/style.css`.
- **Фото/видео** — сейчас градиентные плейсхолдеры; карточки готовы к подмене
  на WebP (`hero-workout.webp`, `workout-*.webp` из спеки) без переработки вёрстки.

## Известные ограничения демо
- Платежи/подписка — мок; юрдокументы — заглушки до текста юриста.
- Уведомления по серверному времени (UTC), без таймзон пользователей; ключи
  «отправлено сегодня» хранятся в памяти — после перезапуска возможен повтор
  за текущую минуту.
- «Ты занимаешься регулярно уже N недель» считается по неделям текущего месяца.
