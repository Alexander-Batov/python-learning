# Структурированная спецификация приложения женского здоровья

> Источник: «Цикл (1).docx». Повторы в исходнике (ТЗ MVP продублировано 3 раза) убраны, данные сведены в одну систему.

---

## 1. Концепция продукта

**Персональный помощник по женскому здоровью и образу жизни.**
Формула: **Цикл → состояние → рекомендации → действие → привычка → результат**

- Цикл — точка персонализации, а не единственная ценность.
- Приложение — не информационный курс, а регулярно используемый сервис (подписочная модель, ориентир 490–790 ₽/месяц).
- Персонализируется **точка входа и контекст** (день/фаза цикла), а **содержание программы стандартизировано**:
  - тренировки — единая программа для всех;
  - питание — единая экспертная система;
  - привычки — общая библиотека, пользователь отмечает выполнение.
- Позиционирование: не «подстройся под идеальный режим», а «адаптируй здоровые привычки под свой цикл, состояние и реальную жизнь».

### Пользовательский цикл
Открыла → увидела, где она в цикле → получила план на сегодня → сделала → отметила → увидела прогресс → вернулась завтра.
Целевое время ежедневного взаимодействия: 1–3 минуты.

### Результат за месяц (поведенческий, без медицинских обещаний)
Понимание цикла · регулярная активность · структурное питание · несколько закреплённых привычек · собственная статистика.

## 2. Ключевые продуктовые правила (обязательны к соблюдению в коде и текстах)

1. **Медицинский safety layer**: приложение не диагностирует и не лечит. Не использовать медицинские утверждения («нормализуется гормональный фон», «исчезнет ПМС»). Рекомендации — wellness-контент.
2. Прогнозы цикла подавать как ориентир: «Ориентировочно сегодня…», а не «Ваш организм точно находится в…». Предусмотреть ручное изменение данных.
3. **Никаких негативных формулировок**: не «ты пропустила тренировку», а «вот что ты уже сделала». Нет «серия прервана», «начни с нуля», сравнений с другими женщинами. Сравнение только «я сейчас ↔ я раньше».
4. Тренировка дня — рекомендация, не предписание. Всегда есть альтернатива («сегодня не хочется интенсивно?» → лёгкие варианты: прогулка, растяжка, йога, мобильность, восстановление).
5. Не делать привычки, тренировки и питание обязательными; формируем регулярность, а не идеальность.
6. Контент появляется **по контексту** («ты сейчас в начале цикла — хочешь узнать, что происходит?»), а не как библиотека/онлайн-школа.
7. Экран не должен выглядеть как медицинский кабинет или трекер; визуально — лёгкий premium wellness.
8. Приложение не диагностирует заболевания; при отметке симптомов, требующих врача, — мягкий редирект к специалисту, а не обычные wellness-рекомендации.
9. Privacy: данные о цикле и самочувствии — чувствительные. Пользователь должен иметь возможность удалить данные/аккаунт без сложного квеста. Согласия и политика конфиденциальности — до запуска.

## 3. Структура приложения

Нижняя навигация — **5 разделов**: `Сегодня` · `Цикл` · `Активность` · `Питание` · `Профиль`.
«Привычки» отдельным пунктом навигации **не делаем** (MVP) — привычки живут в «Сегодня» и «Профиле».

### Onboarding (5 экранов)
1. Приветствие: «Забота о себе — это не цель. Это образ жизни» → Начать.
2. Имя («Как вас зовут?») — имя используется в приветствии.
3. Данные цикла: дата последней менструации, средняя длина цикла, длительность менструации. Опция «Не знаю» → стандартное значение, правится позже.
4. Цели (множественный выбор): регулярная активность · сбалансированное питание · полезные привычки · лучше понимать цикл · больше заботы о себе.
5. Уведомления: «Напоминать о планах на сегодня?» → Да / Позже.

### Экран «Сегодня» (главный)
За 5–10 секунд отвечает: где я в цикле? что делать сегодня? что уже выполнено?

- **Header**: «Добрый день, {имя} ♡» + дата; справа аватар → Профиль.
- **Карточка цикла** (самая заметная): «День N», фаза, горизонтальный индикатор цикла (1 ─── N● ─── длина), «До следующей менструации ≈ X дней», CTA «Подробнее о цикле →». Если данных нет — карточка-заглушка «Настрой приложение под свой цикл».
- **Фраза дня** — меняется по фазе, без медицинских утверждений.
- **Карточка активности**: тренировка дня (название, длительность, интенсивность, оборудование), CTA «Начать тренировку», ссылка «Выбрать другую активность».
- **Карточка питания**: фокус дня («сбалансированная и сытная тарелка») + короткое объяснение, CTA «Посмотреть рекомендации».
- **Карточка привычки дня**: одна привычка, отметка в один клик (○ → ✓, отметку можно отменить).
- **Мини-чек-ин** «Как ты себя чувствуешь сегодня?»: Энергия (😴😐🙂😊⚡), Настроение (😞😐🙂😊🤩), Самочувствие (плохо/нормально/хорошо). Сохранение автоматическое, ~30 секунд на весь чек-ин.
- **Прогресс дня**: progress bar «2 из 3 выполнено» + список ✓ Тренировка ✓ Чек-ин ○ Привычка.
- **Первый вход без данных цикла**: вместо карточки цикла — «Настрой приложение под свой цикл» → онбординг данных.
- Визуальная иерархия: 1) день цикла → 2) что делать → 3) отметить → 4) самочувствие → 5) прогресс. Главная карточка — крупнее остальных.

### Экран «Цикл»
- Текущий статус: день + фаза.
- Месячный календарь: дни менструации, текущий день (терракота), предполагаемая следующая менструация.
- Отслеживание: начало/конец менструации, интенсивность, боль, настроение, энергия, сон, аппетит, тяга к продуктам, вздутие, другие симптомы.
- Информация о текущей фазе (короткий экспертный текст: что происходит, активность, питание, восстановление).
- 4 карточки фаз (Менструация / Фолликулярная / Овуляторная / Лютеиновая) → информационные экраны.
- CTA «Изменить данные цикла» (дата последней менструации, длина цикла, длительность менструации).

### Экран «Активность»
- Header + подзаголовок «Двигайся в своём ритме…».
- **Главная карточка «Сегодня · День N»**: тренировка дня + CTA «Начать тренировку».
- **Альтернатива**: «Сегодня не хочется интенсивно? → Выбрать другую активность» (кликабельна целиком).
- **Фильтры** (горизонтальный скролл): Все / Силовые / Кардио / Йога / Растяжка / Восстановление; по длительности: 10/20/30/40+ мин; по интенсивности: лёгкая/средняя/высокая.
- **Каталог тренировок** — карточки: название, «30 мин · средняя», тег («без оборудования»), фото, кнопка «Начать»; после выполнения — «✓ Выполнено».
- **Моя активность**: «На этой неделе 3/4 тренировки», индикаторы дней недели (✓/—), «Ты занимаешься регулярно уже 2 недели 💛».
- **Месяц**: 12 тренировок · 360 минут · 75% выполнения плана → «Вся статистика →».
- **Экран тренировки**: до (что понадобится: коврик, вода; структура: разминка 5 / основной блок 20 / заминка 5; «Начать») → во время (упражнение, видео/анимация, таймер, этап, прогресс; Пауза / Пропустить) → после («Готово! ♡ · 30 минут активности», «Отметить выполненной» → в статистику).
- Состояния: Начать → Продолжить → ✓ Выполнено. Пропуск дня — без негатива, на следующий день новая рекомендация, статистика сохраняется.

### Экран «Питание»
- Header + подзаголовок; ⓘ — дисклеймер «рекомендации информационные, не заменяют консультацию врача/диетолога».
- **Карточка цикла**: «День 19 · Лютеиновая фаза» + короткая характеристика периода + «Подробнее о питании в этой фазе →».
- **Фокус на сегодня**: сбалансированные приёмы пищи + визуальная тарелка (½ овощи/фрукты, ¼ белок, ¼ углеводы, + жиры) + CTA «Собрать свою тарелку →».
- **«Обрати внимание на»** (горизонтальный список): 🥚 Белок · 🥬 Клетчатка · 🥑 Полезные жиры · 💧 Жидкость (с пояснением «зачем»).
- **«Что приготовить сегодня?»**: карточки завтрак/обед/ужин/перекус с временем (10/20/30 мин) → «Все рецепты →».
- **Рецепты**: фильтры (завтрак/обед/ужин/перекус, быстро, бюджетно, минимум ингредиентов, без готовки/meal prep); карточка: фото, название, «20 минут · 5 ингредиентов» (калории — только если корректно рассчитаны, на старте лучше без них).
- **Конструктор тарелки**: выбор Белок → Овощи/фрукты → Углеводы → Жиры → «Твоя тарелка готова ✓» → «Сохранить в мои блюда».
- **Питание в течение цикла**: навигация по 4 фазам, текущая подсвечена; по нажатию — короткий материал по питанию фазы (без «магических продуктов» для фаз).
- **Трекер питания**: ○ Завтрак ○ Обед ○ Ужин ○ Перекус → ✓; отслеживается факт выполнения, **без оценки «хорошо/плохо»**.
- **Регулярность**: «Питание отмечено 6 из 7 дней», «3 недели регулярного питания».
- Состояния: цикл не настроен — «Настрой свой цикл»; пропуск — «Сегодня новый день. Продолжай с текущего приёма пищи».

### Привычки (экран/блок)
- Принцип: **1–3 привычки одновременно**, постепенное наращивание (неделя 1: овощи в один приём пищи → неделя 2: прогулка 10 мин → неделя 3: стабильное время сна).
- **Фокус недели**: карточка «🌱 Фокус недели: 10 минут прогулки после ужина», цель 5 дней, прогресс ●●●○○, «✓ Выполнила сегодня» → «Отлично! 4 из 5 💛».
- **Мои привычки**: карточки с частотой и прогрессом (💧 вода 6/7 · 😴 сон 4/5 · 🚶 прогулка 3/5).
- **Добавить привычку**: категории (Сон, Питание, Движение, Восстановление — +Вода/Стресс/Забота о себе в полной версии) → частота (каждый день / 3 раза в неделю / 5 раз в неделю / по будням) → напоминание (не нужно / время) → «Добавить привычку».
- **Прогресс**: «12 выполнений · 78% регулярность», «самая стабильная привычка: 🚶 прогулки — 6 из 7»; за месяц — календарь ✓/○ + «Активных привычек: 3 · Выполнено: 47 · Регулярность: 82%». Главная формулировка: «Ты становишься регулярнее».
- Связь с циклом — мягко: «Сейчас лютеиновая фаза. Если чувствуешь снижение энергии, выбери более лёгкую цель на сегодня» + «Адаптировать сегодня →».
- Без наказания: не «серия прервана», а «Сегодня не получилось — это нормально. Продолжи завтра».

### Экран «Профиль»
- Аватар + имя + «Редактировать профиль» (только необходимые данные).
- **🌸 Мой цикл**: длина, последняя менструация, текущий день → «Изменить данные» (правка вручную обязательна).
- **🎯 Мои цели** (выбранные) → «Изменить цели».
- **📊 Мой прогресс** (месяц): тренировки, минуты, дни с отмеченным питанием, выполненные привычки, общая регулярность → «Подробная статистика →».
- **Карточка регулярности**: «82%», динамика по неделям (65 → 74 → 81 → 82), «Ты становишься регулярнее 💛».
- **⭐ Подписка**: тариф, дата списания, способ оплаты, отмена, восстановление покупки; для free — «Перейти на Premium →».
- **Настройки**: уведомления (план дня, тренировка, привычка, чек-ин, начало менструации) · приватность (политика, управление данными, удалить аккаунт) · единицы измерения (кг/фунты, см/дюймы).
- **Помощь**: FAQ (как работает приложение, как считается цикл, как изменить данные, как отменить подписку) · «Связаться с поддержкой».
- **Эксперты**: блок о том, что рекомендации разработаны с командой экспертов (тренер, нутрициолог/диетолог, гинеколог).
- **Юридия**: пользовательское соглашение, политика конфиденциальности, согласие на обработку данных, версия приложения.

### «Моё состояние» / аналитика
Динамика: энергия ↗↘, настроение, сон, активность, питание, симптомы. Простые наблюдения: «Ты отмечаешь более низкую энергию последние 3 дня», «В дни, когда ты спишь менее 7 часов, энергия в среднем ниже».

## 4. Бизнес-логика

### Логика цикла
Дата последней менструации + средняя длина цикла → текущий день → ориентировочная фаза → показ контента.
Обязательно: ручное изменение даты, отметка начала новой менструации, корректировка средней длины, обработка отсутствия данных и нерегулярного цикла. Прогноз — не медицинский факт.

### Логика рекомендаций
Не создавать индивидуальный план. Текущий день → фаза → подходящий контент из заранее подготовленной библиотеки (например, из 20 тренировок, помеченных для фазы, показывается одна). То же с питанием. День цикла и фаза **не зашиваются в код интерфейса** — считаются из данных пользователя.

### Система отметок
Каждое действие: ○ Не выполнено / ◐ В процессе / ✓ Выполнено. После отметки обновляются дневной, недельный и месячный прогресс.

### Мотивационная система «Твой путь к себе»
Баллы «лепестки заботы» за отметки (тренировка +30, питание +15, вода +10, привычка +10, чек-ин +5, закрытый день +20 — константы в конфиге). Уровни от total_earned: Начало 0–100, Баланс 101–250, Энергия 251–450, Гармония 451–700, Расцвет 701+ (обмен призов списывает баланс, уровень не понижает). Достижения, призы, умные напоминания — по файлу `Мотивационная_система.md` (7 экранов, референс `Экраны/Референс_дизайн_полный.png`). Жёстко: не обнулять прогресс, никакой вины, заблокированное — контур + замочек.

### Уведомления (MVP)
- Утро: «Доброе утро ♡ Сегодня для вас подготовлено: активность, питание, привычка» → «Открыть приложение».
- Вечер: «Как прошёл ваш день? Отметьте выполненные действия и сохраните свой прогресс».
- Все уведомления отключаемые (по типам).

### Специальные сценарии (будущее, закладываем архитектурно)
«Хочу больше энергии» (фокус на сон/питание/нагрузку/восстановление) · «Хочу начать тренироваться» (программа 4 недели) · «Хочу наладить питание» · «Хочу лучше понимать цикл». Особенности здоровья, включая режим «Эндометриоз» (wellness-адаптации + отслеживание симптомов; медицинский контент — только после проверки специалистом).

## 7. Объём MVP

**Делаем**: регистрация, onboarding, данные цикла, расчёт дня/фазы, экран «Сегодня», календарь цикла, библиотека тренировок + отметки, библиотека рецептов, питание + конструктор тарелки, привычки, wellbeing чек-ин, статистика, уведомления, профиль, подписка, политика конфиденциальности и пользовательское соглашение.

**Не делаем на первом этапе** (только закладываем архитектурно): AI-коуч, чат с врачом, консультации, Apple Health / Google Health Connect, анализ гормонов, диагностика, сообщество, соцлента, соревнования, сложная персонализация тренировок и питания.

## 8. Критерии приёмки (экран)
Фон, цвета, типографика соответствуют референсу · иерархия всех областей экрана сохранена · главная карточка повторяет градиент и композицию · скругления/отступы/кнопки согласованы · фильтры работают без переноса строк · статистика считается из данных, а не захардкожена · навигация fixed с safe area · нет горизонтального переполнения · все интерактивные элементы работают · изображения оптимизированы · проверены состояния загрузки/ошибки/пустого списка.
